    Visão Geral

    Phoenix é um framework de desenvolvimento web escrito em Elixir que implementa o padrão Model View Controller (MVC) do lado do servidor. Muitos de seus componentes e conceitos parecerão familiares para aqueles com experiência em outros frameworks web como Ruby on Rails ou Django do Python.

    Phoenix oferece o melhor dos dois mundos - alta produtividade para desenvolvedores e alto desempenho da aplicação. Também possui algumas novidades interessantes como channels para implementação de recursos em tempo real e templates pré-compilados para velocidade impressionante.

    Se você já está familiarizado com Elixir, ótimo! Se não, existem vários lugares para aprender. Os guias do Elixir e a página de recursos de aprendizado do Elixir são dois ótimos lugares para começar.

    Os guias que você está vendo atualmente fornecem uma visão geral de todas as partes que compõem o Phoenix. Aqui está um resumo do que eles oferecem:

    • Introdução - os guias que você está lendo atualmente. Eles mostrarão como colocar sua primeira aplicação em funcionamento

    • Guias - guias detalhados cobrindo os principais componentes do Phoenix e aplicações Phoenix

    • Autenticação - guia detalhado sobre como usar o mix phx.gen.auth

    • Componentes em tempo real - guias detalhados sobre os componentes em tempo real integrados do Phoenix

    • Testes - guias detalhados sobre testes

    • Implantação - guias detalhados sobre implantação

    • How-to's - uma coleção de artigos sobre como alcançar determinados objetivos com Phoenix

    Se você preferir ler estes guias como um EPUB, clique aqui!

    Note que estes guias não são uma introdução passo a passo ao Phoenix. Se você quiser uma abordagem mais estruturada para aprender o framework, temos uma grande comunidade e muitos livros, cursos e screencasts disponíveis. Veja nossa página da comunidade para uma lista completa.
