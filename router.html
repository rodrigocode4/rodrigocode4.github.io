    Guia rápido de roteamento

    Estas rotas precisam ser declaradas no módulo e escopo de roteamento corretos.

    Uma referência rápida para a sintaxe de recursos comuns de roteamento. Para uma visão geral completa, consulte os guias de roteamento.

    Declaração de rotas

    Rota única 

    get "/users", UserController, :index
patch "/users/:id", UserController, :update
    # rotas geradas
~p"/users"
~p"/users/9" # user_id é 9

    Também aceita put, patch, options, delete e head.

    Recursos

    Simples

    resources "/users", UserController

    Gera :index, :edit, :new, :show, :create, :update e :delete.

    Opções

    resources "/users", UserController, only: [:show]
resources "/users", UserController, except: [:create, :delete]
resources "/users", UserController, as: :person # ~p"/person"

    Aninhados

    resources "/users", UserController do
  resources "/posts", PostController
end
    # rotas geradas
~p"/users/3/posts" # user_id é 3
~p"/users/3/posts/17" # user_id é 3 e post_id = 17

    Para mais informações, consulte a documentação de recursos.

    Escopos

    Simples

    scope "/admin", HelloWeb.Admin do
  pipe_through :browser

  resources "/users",   UserController
end
    # auxiliares de caminho gerados
~p"/admin/users"

    Aninhados

    scope "/api", HelloWeb.Api, as: :api do
  pipe_through :api

  scope "/v1", V1, as: :v1 do
    resources "/users", UserController
  end
end
    # auxiliares de caminho gerados
~p"/api/v1/users"

    Para mais informações, consulte a documentação de rotas com escopo.
